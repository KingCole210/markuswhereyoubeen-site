# Props

The base colour maps were kept and scaled down to 512 px; the normal, roughness and occlusion maps were dropped (the game draws everything toon-shaded). Each file is the model converted to a single glTF JSON.

- `gourd.json`: "Gaara's Gourd (Naruto)" (https://sketchfab.com/3d-models/gaaras-gourd-naruto-23e7388458444f598fc3dad7bd1ca2b2) by Doverlock (https://sketchfab.com/Doverlock), licensed under CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/)
- `asuma_knife.json`: "Asuma's Kunai from Naruto's Anime" (https://sketchfab.com/3d-models/asumas-kunai-from-narutos-anime-c6047317b8654a40b410ff0f1d7323f1) by Issgarra (https://sketchfab.com/Issgarra), licensed under CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/)
- `exam_hall.json`: "naruto Sala Examen Chunnin" (https://sketchfab.com/3d-models/naruto-sala-examen-chunnin-e2d7e1d570534b1ea7872992e5e3be8c) by Rida.Sidi.Ben.Ali (https://sketchfab.com/Rida.Sidi.Ben.Ali), licensed under CC BY 4.0 (http://creativecommons.org/licenses/by/4.0/)
